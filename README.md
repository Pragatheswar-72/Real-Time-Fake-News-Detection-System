Real-Time Fake News Detection System

A real-time fake news detection web application developed using Python, FastAPI, BERT, and NLP techniques.
The system analyzes news headlines/articles and predicts whether the news is REAL or FAKE with a confidence score.

The project uses Hugging Face Transformers, DistilBERT, and PyTorch for text classification, while NewsAPI is integrated to fetch live news headlines in real time. The frontend is built using HTML, CSS, and JavaScript with features like dark mode and live news updates.
